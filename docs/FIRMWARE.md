# Прошивки станций

## Mini 2: почему нужен `.46`

Заводская прошивка Mini 2 `0.17.1.32…factory-3` **не открывает ADB**.
Для разблокировки нужна сборка `0.369.1.46.4778262943.20261013.299`
(далее `.46`): локальный сервер отдаёт её станции, после установки
поднимается `adbd` на 5555.

## Откуда взять `.46`

1. **Ассет релиза GitHub** (уже приложен):
   `firmware-yandexmini_2-0.369.1.46.4778262943.20261013.299.zip`
   на странице релиза `v1.6.16` и новее.
2. **Официальный CDN Яндекса** (тот же файл из манифеста):
   ```
   https://cdnriqbxswemmatxzibl.svc.cdn.yandex.net/yandexmini_2/ota/user/7ce77cd8-0dba-45ab-8938-b751dc2d1988/0.369.1.46.4778262943.20261013.299.zip
   ```
   Резерв:
   ```
   https://quasar.s3.yandex.net/yandexmini_2/ota/user/7ce77cd8-0dba-45ab-8938-b751dc2d1988/0.369.1.46.4778262943.20261013.299.zip
   ```

Размер: `67 796 480` байт.
SHA-256: `192aa9842c77257c4955c9a02cea837f91217d25206d2368815700280ab3c8c3`.
CRC32: `1524631406`.

## Куда положить

Любой из вариантов:

```
firmware\0.369.1.46.4778262943.20261013.299.zip
data\ota\yandexmini_2\0.369.1.46.4778262943.20261013.299.zip
```

После этого `GET /api/firmwares` показывает `"local": true`, и стек
`local-ota` может отдать прошивку станции.

## Как обновлять

1. В шаге 1 выберите модель `Station Mini 2` и прошивку `.46`.
2. В шаге 2 включите «Разрешить обновление» (по умолчанию выключено —
   станция не обновится без согласия).
3. Запустите службы и дождитесь скачивания/установки; после
   перезагрузки ADB 5555 должен открыться.

Ничего не скачивается и не устанавливается без явного действия
пользователя: прошивка только лежит рядом, сервер отдаёт её по запросу
станции после разрешения.
