# Прошивки станций

## Правовая сторона

Прошивка Яндекса — проприетарный файл. **Хранить её в репозитории или
выкладывать ассетом релиза = распространять чужой продукт**; это риск
для проекта (претензия правообладателя, снятие релиза). Поэтому в git и
релизах её нет.

Что допустимо и что делает программа:
* скачать файл с **официального CDN Яндекса** по явной команде
  пользователя (одно нажатие, без фоновых загрузок);
* принять файл, который пользователь добыл сам, через `ota import`;
* проверить CRC/размер и только потом отдать станции;
* ничего не устанавливать без галочки «Разрешить обновление».

## Mini 2: почему нужен `.46`

Заводская `0.17.1.32…factory-3` не открывает ADB. Для разблокировки
нужна `0.369.1.46.4778262943.20261013.299` (`.46`): локальный сервер
отдаёт её станции, после установки поднимается `adbd` на 5555.

## Как получить `.46`

1. В панели: шаг 5 → «Скачать 0.369.1.46… с CDN» — программа скачает
   файл с официального CDN и положит в `firmware/`.
2. Или вручную:
   ```
   cockpit ota fetch --manifest data/manifests.json \
     --platform yandexmini_2 \
     --version 0.369.1.46.4778262943.20261013.299
   ```
   затем скопируйте `data/ota/yandexmini_2/<версия>.zip` в
   `firmware/<версия>.zip`.
3. Или свой файл: `cockpit ota import --platform yandexmini_2 --file …`.

Официальный URL (из манифеста):
```
https://cdnriqbxswemmatxzibl.svc.cdn.yandex.net/yandexmini_2/ota/user/7ce77cd8-0dba-45ab-8938-b751dc2d1988/0.369.1.46.4778262943.20261013.299.zip
```
Резерв: `https://quasar.s3.yandex.net/yandexmini_2/ota/user/7ce77cd8-0dba-45ab-8938-b751dc2d1988/0.369.1.46.4778262943.20261013.299.zip`

Размер: `67 796 480` байт.
SHA-256: `192aa9842c77257c4955c9a02cea837f91217d25206d2368815700280ab3c8c3`.
CRC32: `1524631406`.

## Куда положить

```
firmware\0.369.1.46.4778262943.20261013.299.zip
```

После этого `/api/firmwares` показывает `"local": true`, и `local-ota`
может отдать прошивку станции.

## Порядок обновления

1. Шаг 1 — модель `Station Mini 2`.
2. Шаг 2 — прошивка `.46`, включить «Разрешить обновление».
3. Запустить службы, дождаться установки и перезагрузки — ADB 5555
   откроется.

Без включённой галочки станция получает `{"hasUpdate":false}`.
