# Локальная веб-панель

```bash
cockpit ui --port 8899
# открыть http://127.0.0.1:8899
```

* форма: адрес ADB, манифест, платформа, версия, прошивка, сторож, CA;
* кнопки: «Активировать», «Диагностика», «Журнал»;
* результат — в панели лога.

Панель не дублирует логику: кнопки вызывают тот же `cockpit` подпроцессом,
поэтому поведение совпадает с CLI, а журнал общий.

Слушает только `127.0.0.1`; наружу не выставлена. Позже обернём в нативное
окно (Tauri/pywebview) без изменения страницы.
