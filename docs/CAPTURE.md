# Сбор статистики: только метаданные, только по согласию

## Зачем

Понять, какие OTA предлагаются, какие конфиги приходят, где ошибки —
на массиве разных колонок и прошивок.

## Что пишется

`Sample`: время, хост, метод, путь **без query**, статус, размеры запроса и
ответа, SHA-256 тел, необязательная заметка. **Тела не сохраняются.**

## Чего не пишем никогда

* токены, `device_id`, MAC, SSID, пароли;
* query-строки (там бывают секреты) — обрезаются;
* полные тела запросов/ответов.

## Включение

Только явно: файл `data/capture.jsonl` создаётся командой/флагом, по умолчанию
сбор выключен. Перед включением показывается пример записи.

## Команды

```bash
cockpit capture stats --log data/capture.jsonl
```

## Ограничения

* один обмен = одна строка, без реконструкции диалога;
* нет автоматической отправки куда-либо: журнал локальный, экспорт — вручную;
* при сомнении удаляйте журнал: он не нужен для работы.
