# Согласие на телеметрию

## Как это выглядит

При первом запуске (`cockpit run …`) в терминале появляется короткое окно-опрос:

```
Помочь проекту? Можно включить сбор метаданных обмена с облаком.
  пишем: время, хост, метод, путь без query, размеры, SHA-256 тел
  не пишем: тела, токены, device_id, SSID, пароли
  куда: локальный файл data/capture.jsonl, никуда не отправляется
Включить сбор? [y/N]:
```

* по умолчанию — **нет** (пустой ответ = отказ);
* ответ сохраняется в `data/consent.json`, повторно не спрашиваем;
* в неинтерактивном режиме (CI, скрипты) вопрос не задаётся — сбор выключен;
* отозвать можно в любой момент: `cockpit telemetry disable`.

## Команды

```bash
cockpit telemetry status
cockpit telemetry enable
cockpit telemetry disable
cockpit capture stats --log data/capture.jsonl
```

## Что именно собирается

Только метаданные: хост, метод, путь без query, статус, размеры, SHA-256 тел,
время. Тела не сохраняются, отправки наружу нет.

## Почему не «настаиваем»

Обязательный сбор обходят, а доверие теряется быстрее, чем набирается база.
Добровольное и обратимое согласие даёт более честные данные на длинной дистанции.
