cockpit — локальная настройка и обслуживание Яндекс Станций
================================================================

Быстрый запуск панели
---------------------
Двойной клик по cockpit.exe (с версии 1.2.3) — панель сама поднимется
на порту 8790 и откроет браузер. Разрешите запрос UAC: панели нужны
сетевые действия.

То же самое делает cockpit.cmd. Если браузер не открылся, зайдите
по адресу http://127.0.0.1:8790/ вручную.

CLI
---
cockpit.exe --help              — справка по командам
cockpit.exe ui --port 8790      — принудительно запустить панель
cockpit.exe version             — версия

Без аргументов cockpit.exe теперь запускает панель, а не печатает
справку. Для справки используйте --help.

Что внутри
----------
cockpit.exe   — программа (CLI + веб-панель)
cockpit.cmd   — запуск панели одним кликом (Windows)
cockpit.ps1   — то же, PowerShell-скрипт
README.txt    — этот файл

Шаг 2 «Настройка»
-----------------
Тип подключения (Wi-Fi / провод) и его настройка находятся здесь.
Для провода есть кнопка «Обновить» — если Ethernet подключили уже
после запуска. «Автоопределение адреса устройства» включено по
умолчанию; при нём поля адреса станции и шлюза заблокированы.

Оффлайн
-------
Панель и сопряжение работают локально. Для проводного режима Хаба
используется POST /connect с wifi_type="NONE"; облако не требуется.

Локальный сервер Хаба (quasar)
------------------------------
В папке data/probe/quasar лежат fake-quasar.py, quasar-chain.pem и
quasar-leaf.key. Для проводного режима нужен Python 3 в PATH: панель
запускает fake-quasar.py на 443. Без него Хаб после /connect ответит
NO_INTERNET, потому что ему некуда регистрироваться.

Если Python не установлен — поставьте Python 3 и перезапустите панель.
