cockpit — локальная настройка и обслуживание Яндекс Станций
================================================================

Быстрый запуск панели
---------------------
1. Двойной клик по cockpit.cmd.
2. Разрешите запрос UAC (панели нужны сетевые действия).
3. Откроется браузер: http://127.0.0.1:8790/

Если браузер не открылся — зайдите по адресу http://127.0.0.1:8790/ вручную.

Почему cockpit.exe закрывается
------------------------------
cockpit.exe — это CLI. Без аргументов он печатает справку и выходит,
поэтому окно консоли при двойном клике сразу закрывается. Это нормально.

Запустить панель из консоли:

    cockpit.exe ui --port 8790

Остановить панель: закройте окно консоли (или Ctrl+C).

Что внутри
----------
cockpit.exe   — программа (CLI + веб-панель)
cockpit.cmd   — запуск панели одним кликом (Windows)
cockpit.ps1   — то же, PowerShell-скрипт
README.txt    — этот файл

Оффлайн
-------
Панель и сопряжение работают локально. Для проводного режима Хаба
используется POST /connect с wifi_type="NONE"; облако не требуется.
